# Prompts

Prompts para usar asistentes de IA dentro del marco del proyecto. Siguen la [política de IA](../AI_POLICY.md): la IA ayuda, pero quien firma verifica cada dato y responde de su contribución.

| Prompt | Para qué sirve |
|--------|----------------|
| [Redactar una VEP](draft-vep.md) | Convertir una idea en un borrador que cumpla la plantilla y el Manifiesto, marcando los datos pendientes en lugar de inventarlos |
| [Revisar una VEP](review-vep.md) | Encontrar los puntos débiles de una propuesta antes de enviarla o durante la revisión pública |

Los prompts funcionan con cualquier asistente de IA. Si mejoras alguno, envía un pull request: también se revisan como el resto del proyecto.
